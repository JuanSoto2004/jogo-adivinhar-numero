# Jogo de Adivinhar o Número

Jogo feito em Python onde o computador pensa num número e tens 10 tentativas para adivinhar.

## Funcionalidades
- Número aleatório entre 1 e 100
- 10 tentativas máximas
- Dicas de "muito alto" ou "muito baixo"
- Proteção contra entradas inválidas

## Como usar
1. Abre o terminal
2. Corre o comando: `python jogo.py`
3. Tenta adivinhar o número!

## Tecnologias
- Python 3
